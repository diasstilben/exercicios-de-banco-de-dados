# 🗄️ Exercícios de Banco de Dados

Este repositório contém exercícios e resoluções da materia Banco de Dados (UERJ - IPRJ). O material abrange desde a revisão da matéria de modelagem de dados até práticas com consultas SQL avançadas.

## 🎯 Objetivo

O objetivo principal deste repositório é armazenar as resoluções de problemas passados pelo professor, com um foco especial em subqueries (subconsultas) e cláusulas avançadas, mas sem deixar de lado a outra parte da matéria necessária para as avaliações.
