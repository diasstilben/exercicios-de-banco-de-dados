# 🗄️ Exercícios de Banco de Dados

Este repositório contém exercícios e resoluções da materia Banco de Dados (UERJ - IPRJ). O material abrange desde a revisão da matéria de modelagem de dados até práticas com consultas SQL avançadas.

## 📚 Tópicos Abordados

* **Modelagem de Dados:** Revisão e exercícios focados na estruturação geral e conceitos da disciplina.
* **Subconsultas Correlacionadas:** Práticas com subconsultas que fazem referências às colunas das consultas externas nas quais estão contidas. O repositório inclui exemplos práticos, como buscar funcionários que possuem o maior salário de cada departamento utilizando a função `MAX()`.
* **Cláusulas EXISTS e IN:** Exercícios utilizando `NOT EXISTS` e `NOT IN` para restrição de dados e verificação de existência. Há exemplos de como listar departamentos que não possuem funcionários com salário superior a 10 mil reais.
* **Cláusula UNION / UNION ALL:** Práticas com operações de conjunto. Os exercícios demonstram como unir resultados de tabelas diferentes, lembrando sempre que as colunas devem ser união-compatíveis (como a combinação de Nome, Telefone e Endereço entre as tabelas `Cliente` e `Fornecedor`).

## 🎯 Objetivo

O objetivo principal deste repositório é armazenar as resoluções de problemas passados pelo professor, com um foco especial em subqueries (subconsultas) e cláusulas avançadas, mas sem deixar de lado a outra parte da matéria necessária para as avaliações.
