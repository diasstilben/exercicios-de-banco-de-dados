# 🗄️ Exercícios de Banco de Dados

Este repositório contém exercícios e resoluções com foco na preparação para a prova de Banco de Dados[cite: 1]. O material abrange desde a revisão da matéria de modelagem de dados até práticas com consultas SQL avançadas[cite: 1].

## 📚 Tópicos Abordados

* **Modelagem de Dados:** Revisão e exercícios focados na estruturação geral e conceitos da disciplina[cite: 1].
* **Subconsultas Correlacionadas:** Práticas com subconsultas que fazem referências às colunas das consultas externas nas quais estão contidas[cite: 2]. O repositório inclui exemplos práticos, como buscar funcionários que possuem o maior salário de cada departamento utilizando a função `MAX()`[cite: 2].
* **Cláusulas EXISTS e IN:** Exercícios utilizando `NOT EXISTS` e `NOT IN` para restrição de dados e verificação de existência[cite: 2]. Há exemplos de como listar departamentos que não possuem funcionários com salário superior a 10 mil reais[cite: 2].
* **Cláusula UNION / UNION ALL:** Práticas com operações de conjunto[cite: 2]. Os exercícios demonstram como unir resultados de tabelas diferentes, lembrando sempre que as colunas devem ser união-compatíveis (como a combinação de Nome, Telefone e Endereço entre as tabelas `Cliente` e `Fornecedor`)[cite: 2].

## 🎯 Objetivo

O objetivo principal deste repositório é armazenar as resoluções de problemas passados pelo professor, com um foco especial em subqueries (subconsultas) e cláusulas avançadas, mas sem deixar de lado a outra parte da matéria necessária para as avaliações[cite: 1].
